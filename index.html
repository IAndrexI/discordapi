Option 2: In-App Bot Commands
Send any of these commands to @discordbot:chat.protutech.vip inside the chat client:
Command Description
login-token user <token> Authenticates using your Discord user token. The message is automatically redacted.
ping Verifies connection status and prints your connected Discord username and ID.
guilds status Lists all discovered Discord servers, their IDs, and current bridging state.
guilds bridge <id> --entire Bridges a specific server and immediately creates rooms for all text channels.
guilds bridging-mode <id> create-on-message Auto-bridges channels on-demand only when new messages are posted.
rejoin-space main Sends an invite to your master Discord Space containing all servers.
rejoin-space dms Sends an invite to your Discord Direct Messages Space.
logout Disconnects your Discord session and removes credentials from the bridge.
