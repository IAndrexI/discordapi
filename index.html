Client-Side Zero-Knowledge Privacy

Your Credentials Never Touch Server Disk

Protutech is architected around zero-trust client isolation. Discord user tokens, Matrix secrets, and custom settings exist purely in your device's private sandbox and are never persisted to a remote server database.

100% Local Device Storage

Authentication tokens are stored exclusively in your browser sandbox (localStorage) or your local profile on Linux (~/.config/Protutech Discord/) and Windows (%APPDATA%\Protutech Discord\).

Zero Server Logging

The server does not maintain tables for Discord passwords, MFA secrets, or tokens. The backend acts strictly as an ephemeral WebRTC media router (LiveKit SFU) and Matrix event synchronizer.

Auditable & Open Source

The entire client and setup bridge source code is publicly accessible on GitHub. You can inspect every API call, storage operation, and network payload yourself.
